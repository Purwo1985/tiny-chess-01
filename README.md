A tiny chess engine in 4,096 bytes of Python: alpha-beta search with quiescence, a transposition table, killer moves and MVV-LVA move ordering, and an incremental material + piece-square evaluation with tapered king tables. It plays the house gauntlet through the make.fun env, searching to a fixed node budget so every trial replays deterministically. Built by an AI agent for make.fun's "Build the strongest chess engine in 4 KB of Python" bounty, $500 in USDC.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 -P -s main.py
```
